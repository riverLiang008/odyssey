# 01 / Motivation

> 可选章节卡：TXT-001

**▶ 镜头 005｜【R】真人正面开场**  `素材：R-001`

最近，我开始为自己设计一个个人网站。

**▶ 镜头 010｜【R+M】真人出镜；可穿插现有作品画面，不必制作新动画**  `素材：R-002 + EDIT-001`

我学的是软件工程，也一直在从事相关的工作。除此之外，我还有一些看起来不太相关的兴趣。我喜欢写作，有自己的随笔集；我喜欢研究一些问题，也会尝试把自己的想法整理成文章和模型；我还制作不同类型的视频，包括一些关于文学、电影和个人思考的内容。最近，我也独立设计和开发了一个 AI Agent 项目，叫作 Odyssey。

**▶ 镜头 015｜【M｜蒙太奇】Odyssey、River、文章和视频素材依次出现，最后汇聚到网站**  `素材：EDIT-002 + SCR-001 + SCR-002 + GFX-001`

过去，这些事情大多是分散的。软件工程是我的专业，写作是我的爱好，视频是另一种表达方式。它们之间似乎没有特别明确的联系。但我逐渐意识到，这些不同的兴趣和实践，其实都属于同一个人。

**▶ 镜头 020｜【R】真人点明网站目标**  `素材：R-003`

所以，我想做一个网站，把它们放在一起。一方面，它可以作为我的个人作品集，也可以用于求职；另一方面，我希望通过它，让别人认识一个更加完整的我。于是，我开始尝试设计。


# 02 / First Portfolio

> 可选章节卡：TXT-002

**▶ 镜头 025｜【R】真人介绍 ChatGPT + Figma 的协作方式**  `素材：R-004`

我使用 ChatGPT 和 Figma 来完成这个过程。最开始，我给 ChatGPT 的要求很简单：简约、克制、有设计感。

**▶ 镜头 030｜【M｜Figma】展示 02 整页，再聚焦四张作品卡片**  `素材：FIG-001`

于是，我们得到了第一个版本，也就是 02。它采用了比较传统的作品集结构：上面是四张卡片，分别介绍我在不同领域的作品；下面则展示我的技能和经历。这个方案其实没有什么明显的问题。

**▶ 镜头 035｜【R】真人解释求职目标和信息层级问题**  `素材：R-005`

但是我很快发现，如果把四张作品卡片作为页面最主要的内容，对于第一次访问网站的人来说，可能会有一点困惑。因为这个网站不仅仅是一个创作者的作品集。我还希望用它来寻找下一份工作。如果一个招聘者打开网站，他可能更想先知道：我具备哪些能力？做过什么事情？有什么作品能够证明这些能力？

**▶ 镜头 040｜【M｜Figma】02→05 前后对比，强调卡片缩小和六个 Expertise 区域**  `素材：FIG-002`

于是，我们重新调整了信息结构。在 05 版本中，四张作品卡片被缩小，成为一个更紧凑的作品入口。下面则用六个独立的章节，介绍我在不同领域的能力、实践经验，以及对应的作品链接。这样一来，网站的信息就清楚多了。我觉得这个版本已经相当不错。但是，它还有另一个问题。


# 03 / Too Much Like a Resume

> 可选章节卡：TXT-003

**▶ 镜头 045｜【M｜Figma】05→06 同构图对比，突出配色变化**  `素材：FIG-003`

最开始的配色有些暗。虽然整体比较统一，但我总觉得它不够明亮，也有一点沉闷。于是，我让 ChatGPT 尝试一套新的配色。这就是 06。新的版本使用了更加明亮的背景，搭配深色文字和蓝色强调色。视觉效果确实好了很多。页面看起来更加清爽，内容也更容易阅读。

**▶ 镜头 050｜【R】真人表达第一次审美上的不满足**  `素材：R-006`

但我看了一会儿，又觉得哪里不太对。它有点太像一张设计精美的简历了。当然，这并不是一件坏事。如果我的目标只是展示专业能力，这样的设计可能已经足够。但我希望这个网站不仅能够说明我做过什么，还能够带有一点属于我自己的气质。我不想把它做得特别夸张。只是希望别人打开它的时候，能够感觉到：这不完全是一个标准化的个人主页。于是，我有了一个新的想法。


# 04 / Split the Page

> 可选章节卡：TXT-004

**▶ 镜头 055｜【R】真人说出原始设计构想**  `素材：R-007`

我问 ChatGPT：能不能把页面分成两半？左边黑底白字，右边白底黑字。甚至同一个文本框，也可以横跨两个色块。这样，当一行文字穿过中间的分界线时，它的颜色也会随之改变。

**▶ 镜头 060｜【M｜新 Motion】简洁分屏动效，文字跨越分界线并反色；可复用 Figma 视觉**  `素材：M-01`

ChatGPT 按照这个想法制作了 07。我第一次看到这个版本的时候，觉得它确实比之前更有辨识度。原本比较普通的页面，突然有了一种很鲜明的视觉特征。

**▶ 镜头 065｜【M｜Figma】07 整页慢速下滚，呈现重复分割和阅读压力**  `素材：FIG-004`

但与此同时，我又觉得它没有想象中那么和谐。左边的黑色似乎太深了。而且整张页面从上到下都被分成两半，视觉上有点沉重。于是，我开始怀疑，是不是配色出了问题。


# 05 / Maybe Not the Color

> 可选章节卡：TXT-005

**▶ 镜头 070｜【M｜Figma】08、09、10 三版本依次切换，可最后三栏并列**  `素材：FIG-005`

我们接着尝试了三套不同的配色。08 使用石板灰和暖白。09 使用鼠尾草绿和象牙白。10 则使用灰靛蓝和奶油白。三种颜色的气质各不相同。有的更加理性，有的更加柔和，也有的更偏向一种冷静的编辑设计风格。

**▶ 镜头 075｜【R】关键转折；建议停顿**  `素材：R-008`

但在看完这些版本之后，我发现，问题似乎并没有真正解决。即使换了颜色，整个页面仍然有一种不太自然的感觉。我开始意识到，也许问题根本不在颜色。而在于深色区域占据了太大的面积。

**▶ 镜头 080｜【R】解释布局问题，接到 11 的画面变化**  `素材：R-009`

最开始，我把黑白分割当成整个页面的设计规则。但它其实不一定需要贯穿所有内容。尤其是下面的六个技能章节，本来就包含了大量文字。如果每一段文字都要穿过黑白分界线，这种视觉效果重复太多次之后，反而会变成一种干扰。

**▶ 镜头 085｜【M｜新 Motion】07→11：深色从整页收缩到 Hero；11 实际页面落版**  `素材：M-02 + FIG-006`

于是，我们尝试把深色区域缩小。只在页面上方保留黑白分割，而下面的内容则恢复成统一的浅色背景。这就是 11。看到这个版本的时候，我觉得，终于有点对了。上面的深色区域让页面具有辨识度，下面的浅色区域则让阅读重新变得轻松。两种视觉语言不再相互竞争，而是承担了不同的作用。不过，我还是觉得有一点可以调整。


# 06 / 45 and 55

> 可选章节卡：TXT-006

**▶ 镜头 090｜【M｜新 Motion】11→12：分割线从 50:50 移动到 45:55，标出比例**  `素材：M-03 + FIG-007`

11 的黑白分割采用了非常工整的 50:50 比例。左右两边各占一半。它很平衡，但也有一点过于对称。于是，我们尝试把比例调整成 45:55。也就是 12。这只是一个很小的变化。没有增加新的元素，也没有重新设计页面。但我觉得，整个构图似乎更加自然了。分界线不再恰好位于页面中心，标题与色块之间的关系也有了一点变化。我开始觉得，这个网站已经接近我想要的样子。但事情还没有结束。


# 07 / One More Idea

> 可选章节卡：TXT-007

**▶ 镜头 095｜【R】真人提出对角色块的构想**  `素材：R-010`

看着 12，我突然想到：既然左上角已经有一个深色区域，那么在页面的右下角，再增加一个同样尺寸的深色色块，会怎么样？这样，整个页面就可以形成一种对角线上的呼应。

**▶ 镜头 100｜【M｜Figma】12→16，突出右下角深色底及其中浅灰内容卡片**  `素材：FIG-008`

于是，我们制作了 16。这个版本确实有它的优点。左上角和右下角的深色色块，让整个页面的构图显得更加完整。我还尝试让右下角深色背景中的内容卡片使用浅灰色，和顶部的作品卡片形成呼应。从视觉设计的角度来说，它似乎更丰富了。

**▶ 镜头 105｜【R】真人提出关键取舍问题**  `素材：R-011`

但当我把 12 和 16 放在一起比较时，我反而开始犹豫。16 的设计感可能更强。可我真的更喜欢它吗？

**▶ 镜头 110｜【M｜Figma】12/16 并排对比，16 淡出，12 留下**  `素材：FIG-009 + EDIT-003`

我发现，右下角增加的色块虽然让构图更加完整，却也让整个页面显得有些刻意。尤其是下面的技能介绍，本来已经有了一套清楚、稳定的阅读结构。新增的深色区域并没有让这些内容变得更容易理解。它更多是在强调设计本身。而我做这个网站的目的，并不是让别人记住一个复杂的页面构图。我希望他们能够通过这个网站，认识我，以及我做过的事情。所以，最后，我还是选择了 12。


# 08 / Looking Back

> 可选章节卡：TXT-008

**▶ 镜头 115｜【R】真人回顾试错过程**  `素材：R-012`

回过头来看，这个过程其实挺有意思的。最开始，我只是想做一个简约、有设计感的个人网站。我并不知道最后它应该长成什么样子。我只是不断地提出想法，观察结果，再决定下一步要怎么修改。

**▶ 镜头 120｜【R+M】真人主画面，插入颜色实验、11/12/16 短蒙太奇**  `素材：R-013 + EDIT-004`

有时候，我觉得问题在颜色上。尝试之后才发现，真正需要调整的是布局。有时候，我觉得页面还可以再增加一点设计感。但真正增加之后，又发现原来的版本反而更好。

**▶ 镜头 125｜【R】真人总结 AI 协作与个人判断**  `素材：R-014`

ChatGPT 在这个过程中帮我快速生成了很多方案，也给了我不少建议。但它并不能直接告诉我，哪一个版本才是最适合我的。因为这个问题本身就没有一个完全客观的答案。我需要通过不断比较，逐渐弄清楚自己真正想要的是什么。这也是我在这次设计过程中觉得最有意思的地方。

**▶ 镜头 130｜【R】结尾观点，放慢语速**  `素材：R-015`

设计并不只是不断增加新的东西。有时候，它也意味着发现一个想法没有预期中那么好，然后愿意把它拿掉。

**▶ 镜头 135｜【M｜Figma】最终 12 全页，依次聚焦 Odyssey / Research / River / Films，最后静止**  `素材：FIG-010 + EDIT-005`

最终，我得到了一个并不复杂的网站。它有一点自己的性格，但又没有那么强烈，以至于盖过里面的内容。而那些内容——软件工程、研究、写作、视频，以及我正在做的各种项目——才是我真正想展示的东西。它们看起来不完全属于同一个领域。但它们都是我。这就是我想做这个网站的原因。
