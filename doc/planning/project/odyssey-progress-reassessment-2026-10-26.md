# Odyssey 开发进度重新评估

日期：2026-10-26

## 当前判断

Odyssey 已从“主要编辑功能具备、关键链路待验”推进到“核心配置流程有完整实测证据，可以准备稳定演示”。10 月 23 日留下的两个画布缺陷已修复；对象存储阻塞已解除；真实上传、Manifest 导入、知识库绑定及保存刷新已有通过记录。

但还不能宣告整个 V1 完成。工作流版本管理、部分文件与图谱信息编辑能力，以及从干净检出到启动的交付验证仍未收口。另外，验收使用的部分成果还在本地工作区，尚未随整改提交进入远程仓库。

- 核对浏览器结构化结果、关键截图和测试日志；收尾浏览器汇总为 10 组通过，视野矩阵另有 32 组记录。不可用知识库的请求证据为 409 / 跨 Workspace 404，拒绝后图与 revision 不变。
- 查看视野映射、Loop 边界处理、Preview 名称加载和菜单焦点等实现，并核对当前 Git 状态。
- 本窗口独立运行针对性 Vitest：**9 文件、38 项通过，exit 0**。覆盖模式切换、Loop 边界及保存恢复、Canvas、Preview、知识库名称加载、Branch、下拉框与菜单。测试有既有 jsdom / Vue Flow 尺寸样式警告。

本次属于证据复核、实现抽查与针对性回归，没有重新执行整条真实浏览器上传链路，也没有重跑全部 PostgreSQL 测试。因此保留原 ToDo 中的独立现场复验栏，不将另一窗口的执行记录改写为本窗口亲测结果。

- [ ] 从干净检出验证依赖安装、环境配置、数据库迁移、对象存储、应用启动及示例导入，确认没有依赖本机遗留数据或未跟踪文件。
- [ ] 验证远程 CI。当前能确认的是本地检查通过，不能据此宣称 GitHub CI 已通过。
- [ ] 将可重复的浏览器套件和必要 fixtures 纳入维护范围；目前关键证据与脚本主要在未跟踪的 `doc/temp`，尚不是仓库内稳定的回归入口。
- [ ] 更新旧计划，区分已完成、未实现和未复验，避免继续按旧的 MinIO 阻塞或“知识图谱未实现”排期。

### 补齐配置型 V1 的功能缺口

- [ ] **工作流版本管理**：显式创建不可变版本、查看历史及恢复 Working Draft。当前自动保存和 JSON 备份不能替代这一项。
- [ ] **文件管理**：文件夹重命名、移动、删除及文档重命名；补齐相关约束和失败行为。
- [ ] **上传管理**：百分比进度、主动取消及明确的重试操作；补齐 staging / orphan 清理证明。已验证“失败后重新选择文件可重试”，不等于完整上传任务管理已完成。
- [ ] **知识图谱信息编辑**：摘要、指南、标签和可审阅关系的编辑保存；补齐返回图谱后的视野恢复、异步切换和大图基准等尚未充分证明的范围。
- [ ] **模型与系统变量目录**：明确 V1 所需的正式资源来源。DSL 已有系统变量 registry，不能继续说系统变量完全没有实现，也不能把本地 registry 当成完整远程目录服务。
- [ ] **完整演示交付**：固定示例、初始化说明、重置方式和部署步骤，完成一次从空环境到演示结束的检查。

Journey 搜索、筛选、排序及知识库分类管理仍可按 V1 范围取舍。工作流执行、模型调用、自动语义索引与检索、Curator / Steward 运行，以及多人协作属于后续执行能力，不计入本轮整改缺陷。
