# Odyssey M2.1 Completion Report

> Status: Complete  
> Completed: 2026-08-12  
> Scope: Contracts, deterministic fixtures, and repository boundary only

## 1. Outcome

M2.1 is complete. Odyssey now has runtime-validated, platform-neutral contracts for the editor data consumed by M2.2, M2.3, M2.6, and M2.7, plus an isolated in-memory repository for frontend development before the real Journey/Agent API exists.

M2.1 did not implement routes, pages, Pinia editor stores, Vue Flow adapters, domain commands, autosave orchestration, or the Figma-designed application interface.

## 2. Implemented boundaries

### Shared schema package

`@odyssey/schemas` now provides:

- common UUID, schema version, revision, UTC timestamp, JSON value, and result primitives;
- Pattern kinds, slots, routes, configuration, and template summaries;
- value sources, template segments, Agent Variables, and Task-local Variables;
- strict discriminated contracts for all five V1 Tool kinds;
- top-level Workflow and Loop-body-specific node unions;
- Workflow Edges using `sourceHandleId` and semantic Graphs without Vue Flow types;
- Canvas Layout using `nodePlacements`, finite coordinates, and persisted viewport;
- Journey and Agent editor projections;
- aggregate replacement save inputs, save results, and structured repository errors.

### Web application boundary

`apps/web/src/repositories` now provides:

- the `EditorRepository` application port;
- an isolated `InMemoryEditorRepository` adapter;
- abort-aware deterministic latency;
- expected-revision compare-and-swap;
- deep-cloned load/save boundaries;
- injectable next network failure, invalid response, and revision conflict through controls that are not exposed by the production port.

### Deterministic fixtures

`apps/web/src/fixtures` now provides fresh, runtime-parsed fixtures for:

- all four built-in Pattern kinds;
- minimal Start → End Workflow;
- research Workflow containing Agent Action, Branch, Task, and End;
- Loop proof containing Loop Start, Task, Agent Action, and Loop End;
- Research, Planner, and Reviewer Agent editor documents;
- the Research System Journey editor document;
- one reusable Knowledge Retrieval Tool and one Knowledge Space reference.

## 3. Stable interfaces after M2.1

The following names and boundary semantics are stable for downstream M2 implementation:

```text
PatternConfig / PatternSlot / PatternRoute / PatternKind
ValueSource / TemplateSegment
AgentVariable / TaskLocalVariable
ToolStep / AgentReusableTool / ToolKind
WorkflowNode / WorkflowEdge / WorkflowGraph
CanvasLayout / NodePlacement / CanvasViewport
JourneyEditorDocument / AgentWorkflowEditorDocument
SaveJourneyInput / SaveAgentWorkflowInput
RepositoryResult / RepositoryError
EditorRepository
```

Frozen naming and shape commitments include:

- schema version `1.0.0`;
- UUID identity at persisted and nested boundaries;
- `nodePlacements`, not `nodePositions`;
- `sourceHandleId`, not Vue Flow `sourceHandle`;
- Graph/Layout separation;
- editor projections that do not expose ORM/JSONB/reference-index implementation details;
- aggregate replacement with `expectedRevision`, not a frontend patch protocol.

## 4. Deliberately deferred rules

The following are not schema responsibilities and remain assigned to later milestones:

- Pattern topology cardinality and route derivation: M2.3;
- command-only Pattern and Agent Slot mutation: M2.3;
- exactly-one Start/End, DAG validation, Branch edge completeness, and other Workflow mutation invariants: M2.6;
- Vue Flow view-model conversion and canvas round-trip adapter tests: M2.6;
- autosave state machine and stale-response protection: M2.8;
- real HTTP repository adapter and API DTO mapping: M3/API integration;
- package and individual-file operational size limits: import/export work.

## 5. Verification

Automated coverage includes:

- canonical positive examples and strict invalid-shape tests;
- UUID, closed-set, discriminated-union, identity, and cross-reference failures;
- clone isolation, repository-instance isolation, CAS conflict, failure injection, abort, and revision independence;
- Journey and Agent load → save → reload round trips;
- fixture freshness and runtime parsing;
- automated scan preventing UI-framework imports and weak `Record<string, unknown>` contracts in the shared schema package;
- persisted-document audit for UI-only, ORM-only, and legacy field names.

The repository quality gate passes through:

```bash
pnpm check
```

This covers lint, schema/Web typecheck, schema/Web tests, and the production Web build.

## 6. Downstream handoff

- M2.2 may use the editor documents, repository port, and Research System fixtures to build the `/journeys` application shell while preserving the existing `/` landing page.
- M2.3 may consume Pattern schemas and fixture templates without introducing alternate persisted Pattern shapes.
- M2.6 may consume Workflow/Loop/Layout schemas and must add domain validation and Vue Flow adapters outside the shared persistence contracts.
- M2.7 may consume the five Tool unions and Value/Variable contracts for type-specific configuration panels.
