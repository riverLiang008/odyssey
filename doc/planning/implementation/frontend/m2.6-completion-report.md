## 3. Frozen behavior implemented

### Structural hard gate

- exactly one Start/End 或 Loop Start/Loop End；
- boundary nodes system-owned and delete-protected；
- endpoints must exist；
- node/edge identity unique；
- self-edge、semantic duplicate edge 和 arbitrary cycle 被拒绝；
- Start/Loop Start 无 incoming；
- End/Loop End 无 outgoing；
- Branch source 必须使用 owned Case/Default handle；
- non-Branch source 不接受 handle；
- each Branch handle 最多一条 outgoing edge；
- top-level / Loop body allowed node kinds 分离；
- nested Loop 被 schema/context boundary 拒绝；
- Loop child structural failure 不修改 parent。
- Loop graph command cannot replace nested placements or viewport。

### Execution readiness diagnostics

- every node reachable from Start；
- every node can reach End；
- every Branch Case/Default handle exactly one outgoing route；
- Loop child graph execution-ready；
- disconnected/incomplete graph 可作为 structurally safe draft，但不会被误报为 executable。

### Atomic command behavior

- command validates source and candidate；
- rejected candidate never replaces source；
- ordinary node removal also removes incident edges；
- node removal never guesses automatic reconnection；
- Branch Case removal atomically removes its route；
- graph command never changes layout；
- store atomically replaces `document.workflow` only on success；
- selected removed node and related panel are reconciled；
- domain diagnostics/session never enter save payload。
