## 2. Architecture boundaries

The implementation preserves:

```text
WorkflowGraph + CanvasLayout
          ↓
workflowCanvasAdapter
          ↓
Vue Flow view model
          ↓ user event
typed intent / store action
          ↓
M2.6 domain command or CanvasLayout command
```

- Vue Flow types remain inside `canvas/workflow` adapter-facing files and Workflow feature UI.
- Vue Flow nodes/edges are derived presentation and are never saved.
- Graph, Layout and editor session remain separate.
- Node drag commits only on drag stop.
- Viewport commits only on move end.
- Node creation/removal returns one graph+layout transaction result.
- Domain/repository/schema contracts contain no Vue Flow view model.

## 3. Scope deliberately deferred

The disabled Palette items and Configure button describe this boundary instead of creating invalid domain data.

## 8. Acceptance remediation — 2026-08-24

The first independent acceptance reported two issues:

- Palette native HTML5 drag/drop did not create a node in real Chromium pointer automation;
- a Vue Flow-rejected connection could leave the previous domain error visible.

Remediation:

- Palette drag now uses a pointer-based coordinator with a six-pixel threshold and an equivalent click/keyboard path;
- Canvas remains the only owner of client-to-flow coordinate conversion;
- native payload serialization remains typed and runtime validated for compatibility;
- capture-stage native drop supports Odyssey JSON plus `text/plain` fallback;
- `connect-start` clears stale feedback;
- a rejected connection produces current typed feedback through either the domain command or Canvas rejection state;
- Canvas UI errors remain session-only and are excluded from the save projection.

Real-browser recheck, without saving new acceptance data:

- Task pointer drag: Canvas node count `5 → 6`;
- Branch pointer drag: Canvas node count `6 → 7`;
- both drops selected the created node and marked the document `Unsaved changes`;
- Branch self-edge returned `Action rejected: self edge.`;
- edge count remained unchanged;
- console warning/error count remained zero.
