## Independent acceptance focus

In a development build, arm one deterministic network failure from the browser console before the next Journey or Workflow save:

```js
window.__ODYSSEY_ACCEPTANCE__.failNextSave()
```

The switch is one-shot, is cleared with `window.__ODYSSEY_ACCEPTANCE__.clear()`, and is not installed when `import.meta.env.DEV` is false.

- delayed edit-during-save produces exactly one follow-up request;
- network failure preserves the newest local document and Retry saves it;
- confirmed Reload discards local changes and loads the newest aggregate;
- confirmed Overwrite fetches the latest revision and performs one CAS save;
- a second conflict remains blocked and recoverable;
- route navigation waits for dirty/saving flush and prompts only after failure/conflict;
- browser refresh/close triggers native protection for unsaved states;
- server-authoritative Guardrail/Agent/Slot commands flush local Pattern changes first and never double-save;
- Focus/Configure/Loop contexts retain save status and keyboard accessibility.
