## 视觉方案

保留左侧 Agent Action 的 Model、Goal、Knowledge Spaces、Toolbox 与右侧 Task 的三项预定义工具步骤；蓝色强调当前讲解对象，另一侧降对比。Model / 工具名称来自设计参考，不代表所有节点必须采用这套配置。

将原图 `Deterministic steps / sequence` 换为已确认的 `Predefined steps / sequence`。Task 内部步骤是本例的预先定义，不是所有 Task 的固定规则；不暗示工具输出完全确定。Agent 侧突出 Goal 与可用资源，不展示虚构思维链或成功执行状态。

两卡并列，无连接两者的执行箭头。默认全屏动画，无真人小窗；未提供真人视频，本稿不替 R-015 标记完成。底部预留约 160px 后期字幕空间，PNG 中中文审阅标记仅用于本轮预览，成片移除。
