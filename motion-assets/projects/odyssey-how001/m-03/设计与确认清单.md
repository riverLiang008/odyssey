## 自己画图时可按这四格

1. Agent Node 与 Task Node 并列，标题 Thinking Ownership / Who makes the decisions?
2. Agent 卡高亮，显示 Goal 与有一定选择空间；不暗示无限权限或必须用多 Agent。
3. Task 卡高亮，显示 Predefined operation，强调按既定操作执行；不写“不能调用 LLM”“每次结果相同”。
4. 完整对照停留，给后续镜头留衔接；两卡之间不用执行箭头。
