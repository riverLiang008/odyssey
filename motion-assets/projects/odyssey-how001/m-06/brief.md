## A. 制作意图与范围

| 项目 | 内容 |
| --- | --- |
| 编号 / 名称 | M-06 / Retrieval vs Graph Navigation |
| 所属视频 | HOW001，第二章；延续 M-05 的文档关系图视觉 |
| 对应镜头 | 163；登记项 M-06，真人部分另属 R-019 |
| 用途 / 观众 | 插入整片的概念解释动画；观众已看过文档节点、关系边与知识组织方式 |
| 核心 idea | 检索帮助找到信息，沿文档关系导航帮助补充上下文；两者可以协作 |
| 看完应理解 | 图导航是对检索的补充；RAG 在设计中仍可作为 Tool，并未被取消 |
| 必须出现 | RAG / Retrieval、文本片段、文档关系、Graph Navigation、互补关系及设计探索属性 |
| 默认范围 | 镜头163完整五段旁白，从 This also made me think again… 至 …navigation through the knowledge graph. |
| 不包含 | 161的 FIG-003 界面交接、175真人回顾、183的 M-07 四概念总结；不自动合并相邻镜头 |
| 事实依据 | [英文分镜 V2 镜头163](../../../../advertise/HOW/001/Odyssey_HOW002_EN_Voiceover_Shot_Segmentation_V2.md)，原文摘录见旁白文件 |

语义约束：这是设计探索，不画成已实现的 Agent 检索运行演示。不声称 RAG 必然丢失上下文、不理解关系或效果更差；旁白的限制条件是“只看小块文本时，可能错过整体和联系”。图箭头保持文档关系含义；若高亮一段路径，只表示概念上的关系浏览，不表示当前系统已执行、已自动选择最优路径或已有工具调用日志。不增加准确率、速度或检索质量指标。

## D. 制作方式

沿用前几支：素材到位后检查 → 语义分镜和关键画面 → 用户审阅 → Motion 实现与导出。本轮不生成虚假的音频、SRT、截图或成片占位文件。

人工最低准备量：本段录音与同版SRT，说明是否同零点；没有特殊视觉要求时由 AI 提案。四至六格草图不是必需输入。
