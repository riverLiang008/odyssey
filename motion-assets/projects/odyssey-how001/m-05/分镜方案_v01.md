## 设计依据与取舍

- SK-08 是飞书草稿，供理解原设计；Editable Static Storyboard.svg 为分镜意图主参考；UI.png 为当前节点、文档标签与文件树的视觉参考。
- 保留 SVG 的“存储与组织分离 → 有向图 → 分组标签 → 网络”叙事，按真实旁白重新编排，不机械照搬六格顺序。
- 每格使用同一批三份文档，名称取自当前 UI：metadata-guidelines.md、relationship-guidelines.md、review-and-change-policy.md。文件夹始终可见，关系图中的同名卡片是同一文档的另一视图，不复制存储、不删除文件树。
- 箭头为概念关系示意，不逐边复制截图，也不代表执行、Agent 导航或检索。原 SVG 的6节点布局不当作当前3文档截图的真实数据；预览明确标为概念图。
- Group 用包含文档的边界，标记为示例 Review context；Tag 为具体文档上的标签，延续 UI 的 Metadata Quality / Graph Relationships / Change Governance。Group 示例需在分镜审阅时确认，不宣称截图里已出现这个命名分组。
- 先用文件树与简图讲清概念，当前 UI 截图不直接缩小塞入画面；本版结尾停留概念网络，不自行将 UI.png 归为 FIG-003 / UI-17。
