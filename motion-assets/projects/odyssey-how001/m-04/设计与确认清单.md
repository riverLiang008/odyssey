## 画示意图可以按这五格

1. 一个 Agent 结构内四张并列配置卡：Model / Goal / Knowledge Space / ToolBox。
2. 四项仍可辨认，但突出 Knowledge Space 与 ToolBox，进入职责区分。
3. Knowledge Space 展开 Knowledge / Instructions / Text resources。
4. ToolBox 展开 Tools / Actions。
5. 两侧同屏，Knowing / Doing 对照，明确共同属于 Agent。

不要把四项画成必须依次执行的流程；不要把 Knowledge Space 与 ToolBox 画成二选一。若提供示例文档或工具，标为例子，不把临时举例当作系统已实现功能。
