## 范围

新增 `how001-fig-001-1.m4a` 与同名 SRT 的两句旁白属于同一解释链：二维结构 → Module / Pattern → Behavior → 是否推进系统 → 配置可见性 → 一处看清结构与就绪情况。因此纳入同一支 M-01。

素材编号保留：M-01 是动画段落，FIG-001 / UI-05 是它后半段引用的产品界面素材；不因音频文件名含 fig 就拆成另一支动画，也不重复播放这两句旁白。

## 输入与时间基准

- 第一段：`how001-m1-1.m4a`，容器时长约 40.384 秒；SRT 6 条，源时间 0～40 秒。
- 第二段：`how001-fig-001-1.m4a`，容器时长约 17.024 秒；SRT 2 条，源时间分别为 0～8.8 秒、8.8～17 秒。
- 工作方案：第一段在 Motion 0 秒开始；第二段在 Motion 40.4 秒（30 FPS 的第 1212 帧）开始。两段各自源时间从 0 开始，不把第二份 SRT 的 0 秒当成整支动画的 0 秒。
- 第二段字幕本地时间 = 第二段 SRT 时间 + 40.4 秒；原始两个 SRT 保持独立，不直接改写第二份源字幕时间。
- 暂定总长 57.433… 秒、1723 帧，覆盖第二段音频在本地 57.424 秒结束的位置。第一段容器末尾至第二段起点约 16 毫秒；这只是帧对齐方案，实际停顿、首尾静音和接缝仍需试听后调整。
