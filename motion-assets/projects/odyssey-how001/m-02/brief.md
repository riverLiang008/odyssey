## A. 制作意图（已预填，人工确认例外或修改）

| 项目 | 内容 |
| --- | --- |
| 编号 / 标题 | M-02 / Workflow Node Taxonomy（工作流节点分类） |
| 视频 | HOW001；原脚本文件名保留 HOW002，见下方来源 |
| 用途 | 整片中的概念解释动画，视觉延续已验收 M-01 |
| 观众 | 对 Agent 系统有基本认识、刚听过简化节点类型的动机 |
| 核心 idea | 从 Workflow Nodes 分成 Logic Nodes 与 Action Nodes，再展开 Action 的 Agent / Task 子类 |
| 应理解的结论 | Logic 控制流转，Action 执行工作；Agent 与 Task 属于 Action，不与 Logic 并列为同一级 |
| 必须出现 | Workflow Nodes、Logic Nodes、Action Nodes、Branch、Loop、Agent Nodes、Task Nodes |
| 语义边界 | 分类连接不是执行顺序；Branch 和 Loop 是 Logic 的例子，不声称穷尽；Agent 与 Task 是并列子类，不画成必须先 Agent 后 Task |
| 默认范围 | 097 的四句旁白；095 的 SK-05 可作引入；107 的 Thinking Ownership 留给 M-03 |
| 不默认纳入 | 091 真人动机段；107 决策权解释；115 LLM 作为 Tool 的旁白与 UI-08。需要扩展时明确记录，不凭相邻关系合并 |
| 来源 | [英文分镜 V2](../../../../advertise/HOW/001/Odyssey_HOW002_EN_Voiceover_Shot_Segmentation_V2.md) 镜头 091、095、097、107、115；登记表 M-02 / SK-001 |

建议用无箭头树状连线或分组容器表达分类，用简短文字辅助说明职责。动画是逐层揭示概念，不是模拟系统运行，不加执行成功、运行脉冲或配置状态填色。
