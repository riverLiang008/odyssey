| 优先级 | 你准备的内容 | 说明 |
| --- | --- | --- |
| 必需 | `how001-m2-1.m4a` + `how001-m2-1.srt` | 建议文件名，可改名。朗读 [旁白原文](./旁白与时间锚点.md) 中四句；从 So I tried… 到 …Agent Nodes and Task Nodes，避免漏掉结尾 |

## 请确认这三项

1. **范围**：建议只做 097 的节点分类，SK-05 可作片头；107 的决策权对比继续属于 M-03。你的修改：待填写（无修改可写沿用）。
2. **结构与设计**：接受下方分类关系、由 AI 设计画面，还是你另附示意？答：待填写。
3. **开头与衔接**：使用 SK-05 草图引入 / 直接出现分类图；结尾保留 Agent 与 Task 供下一支 M-03 衔接。答：待填写。

建议分类结构（缩进表示归类，不是执行顺序）：

```text
Workflow Nodes
├── Logic Nodes                 控制流程
│   └── Examples: Branch, Loop   例子，不声称穷尽
└── Action Nodes                执行工作
    ├── Agent Nodes
    └── Task Nodes
```

## 如果你想自己画示意图

画出最终结构并标注逐层出现顺序即可：

- 第一格：Workflow Nodes → Logic / Action 两组。
- 第二格：Logic 高亮，下方 Branch、Loop 作为例子；标注“控制流程”。
- 第三格：Action 高亮；标注“执行工作”。
- 第四格：Action 分成 Agent、Task 两个子类，保留全图。

连线用无箭头树状线或分组框；不要画 Logic → Action → Agent → Task 的串行链。画面颜色只用于强调分类，不延续 M-01 的“实心表示已配置”语义。无需在 M-02 解释 Thinking Ownership 或 LLM Tool；避免和 M-03 / FIG-002 重复。
