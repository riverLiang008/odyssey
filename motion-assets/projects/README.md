# Motion 项目素材

每支 Motion 使用 `<video-name>/<motion-id>/` 目录，将 [制作表模板](../templates/motion-production-template.md) 复制为 `brief.md`，填写 A～D；旁白放 `narration/`，SRT 放 `subtitles/`，参考素材放 `references/`。

路径引用以 `brief.md` 所在目录为基准，标明文件版本及时间零点。分镜和验收由 AI 补充到同一制作表。音频与视频默认不进入 Git，须另行共享；不要创建虚假的素材文件来补齐目录。详见 [目录约定](../README.md)。
